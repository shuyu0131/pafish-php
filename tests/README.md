## 当前核心契约

- 业务服务继续复用 `DB`，嵌套调用使用保存点；事务中禁止 DDL 和手工提交。迁移器拒绝在已有业务事务中执行。
- 迁移串行执行。普通数据操作按事务分段，DDL 不可整体回滚；迁移作者仍需保证已提交阶段可重试。只支持表/索引结构和普通数据语句，不支持存储程序、自定义分隔符或可执行 SQL 注释。
- 核心、升级器和商店统一走 `Version::compare()`：支持 v 前缀和 PHP version_compare 支持的预发布标记，忽略构建元数据；短数字版本补齐到三段。
- 验证码在当前浏览器的 PHP 会话中按注册/重置用途各保留一份，绑定邮箱，只存哈希；十分钟有效、五次错误失效、验证成功即移除。同一会话锁内消费，默认 files handler 的并发行为已验证；自定义 session handler 须提供同会话互斥。发送间隔仍复用 RateLimiter，不再访问验证码表。旧验证码需重新发送，并在同一浏览器完成操作；退表迁移见文末。
- 文章互动的数据操作经 `PostReactions`；HTTP 入口校验会话 CSRF 并限流。请求可用 `_csrf` 或 `X-CSRF-Token`，`active=1/0` 指定目标状态，重试不会重复加减；未传 active 时保持切换语义。
- 匿名点赞状态保存在服务端会话，旧的 liked_posts cookie 不再作为计数凭据。会话重建、设备切换可能形成新参与者；IP 限流不等于永久身份去重。收藏继续要求登录。
- 匿名互动服务持有最外层事务，拒绝在已有事务内调用，避免数据库回滚后留下错误的会话记录。登录用户关系读取使用锁定读，不受调用方已有快照影响。
- 扩展整数列可显式声明 `unsigned: true`，引用核心 ID 时使用 `bigint` + `unsigned: true`。已有列不隐式改变符号；列级 references 已支持核心表的真实外键，见 docs/extension-kernel.md。

分类泛化、内容历史、实体元数据和跨内容评论/互动尚未实施。媒体引用已接入核心，契约和专项回归见下文。
