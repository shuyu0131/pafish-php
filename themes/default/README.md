# 默认主题：独立更新的开发参考

默认主题随完整 PHP 发行包提供，支持普通主题的独立更新通道；商店是否提示更新取决于 default 条目是否已发布。学习主题开发时，优先对照本目录与 [默认主题子主题教程](../../docs/default-theme-walkthrough.md)。自己的定制放在独立子主题目录，避免主题更新覆盖修改。

默认主题也支持独立发行与应用商店更新，版本来自本目录 theme.json。新安装仍附带默认主题；安装本轮核心更新保护后，系统升级保留现有默认主题目录，缺失时才从系统包补齐。商店更新只替换父目录，保留设置和子主题文件。详见 docs/extension-packaging.md#默认主题独立更新。

| 文件 | 学习内容 |
| --- | --- |
| theme.json | 设置定义、分组、联动，以及明确的系统模板回退 |
| header.php / footer.php | 页面骨架、父子样式、主题和插件注入 |
| style.css / theme.css | 布局与明暗配色分离，通过 CSS 变量换肤 |
| site-brand.php | 设置读取、图片 URL 校验、输出转义和局部模板复用 |
| index.php / home-carousel.php | 首页列表、分页和可选轮播 |
| post.php / post-card.php | 文章详情与列表卡片 |
| default-sidebar.php / sidebar-widgets.php | 默认侧栏与站长配置的组件 |
| comment-thread.php | 评论展示与回复 |

未在本目录提供的模板按 theme.json 的回退声明使用 app/Views/theme 中的系统模板，不必为了示例复制所有文件。默认主题不需要私有业务表或 extension.php。

1.5.1 补齐子主题的桌面站点标识、默认侧栏与页脚主题注入。入门源码在 docs/examples/default-child，不自动安装或切换真实站点主题。

1.5.2 移除文章详情页相关推荐及其设置入口。首页只保留可选的自定义幻灯片，置顶文章回到普通列表，不再作为轮播来源。移除置顶轮播专属的篇数、排序、分类筛选与去重设置，旧 pinned 配置按关闭处理。自定义幻灯片支持纯图片、纯文字和图文，所有信息可选，全空行不展示；图片可上传、从媒体库选择或清除。设置分组为品牌、首页、内容、布局补齐同套导航图标。
