## ✨ 核心改进

### 1. 卡片布局升级
- **预览图**：从无到有，16:9 比例，自动适配
- **悬停效果**：卡片上浮 2px + 阴影加深 + 图片缩放
- **信息密度**：描述精简为 2 行，超出省略

### 2. 响应式设计
- **桌面**（> 768px）：3 列网格
- **平板**（480-768px）：2 列网格
- **手机**（< 480px）：1 列网格

### 3. 详情面板
- **从**：居中弹窗（遮挡内容）
- **到**：右侧滑入抽屉（不遮挡列表）

### 4. 交互反馈
- **按钮加载**：旋转动画 + 禁用状态
- **搜索防抖**：300ms 延迟，减少计算
- **搜索高亮**：匹配的卡片闪烁动画
